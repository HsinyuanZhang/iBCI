## 1. 判定规则

**只有当一个数字是在完全相同的数据、相同的划分、相同的指标上算出来的，才可以直接引用别人论文的数字。否则必须自己复现。**

这把四个数据集分成两类：

| 类别 | 数据集 | 原因 |
|---|---|---|
| **可引用** | FALCON M2、FALCON H1 | 主办方持有隐藏测试集，对所有提交用同一流程打分。别人在该端点上的数字与我们直接可比。 |
| **不可引用** | subject-M（DANDI 000688）、RT | 没有公共基准、划分或指标。每个对照都必须我们自己跑。 |

“差不多一样”不算可引用。会话、窗口长度、R² 定义、训练/测试边界，任何一条不同都会让已发表数字失去可比性。

## 4. 我们赢在哪、输在哪 —— 两者都要写

**H1 held-out 上我们赢过：** 所有 zero-shot 方法（WF 0.16、NDT2 0.10、RNN 0.09）、两个少样本无监督对齐方法（NoMAD 0.13、CycleGAN 0.12）、oracle Wiener Filter（0.21），以及用 held-out 校准训练的 WF（0.11）。

**H1 held-out 上我们输给：** NDT2 Multi 少样本有监督（0.52）和 RNN oracle（0.44）。

**不要隐藏 NDT2 Multi 这个结果。** 它是公开的、在同一端点上的。可辩护的表述是：我们的贡献不是 FALCON 上的最高精度。NDT2 Multi 是一个大型多 session Transformer，做的是少样本**有监督**适配。我们的主张不同：与所有 zero-shot 和无监督适配方法相比持平或更好，**且完全不做目标 session 的反向传播**，identity 路径小 102.6 倍，主办方测得的延迟低约 12%，并且使用事件级而非稠密监督。

按这些维度表述，FALCON 这张表会加强论文；按精度表述，则会毁掉论文。

## 5. 真正区分方法族的维度

单看精度无法区分这些方法。下面七个维度可以，论文应以此作为对比框架。

| 维度 | 各方法的取值范围 |
|---|---|
| 目标 session 的监督 | 无（zero-shot）、仅无标签（对齐）、稀疏标签（我们）、稠密标签（WF/ridge、NDT2 FSS） |
| 新 session 上是否需要反向传播 | NDT2 FSS、CycleGAN、NoMAD、MPA 需要；我们和闭式读出**不需要** |
| 是否需要通道对应 | ridge/WF/Kalman 需要固定单元映射；置换不变的 identity 路径不需要 |
| 适配的对象 | 输入对齐、隐空间对齐、解码器权重，或 identity token（我们） |
| 所需校准数据 | H1 用 4 个 trial、约 60 秒；对齐方法通常需要一整段无标签数据 |
| 是否需要多 session 源域 | NDT2 Multi 和我们需要；WF/Kalman/PV 不需要 |
| 部署代价 | 参数量、MACs、延迟。只有我们和 MPA 报告这一维度 |

我们的独特位置在于这四者的**同时成立**：稀疏有标签监督、目标 session 无反向传播、不需要通道对应、identity 路径很小。表中没有任何其他方法同时占据这四点。

## 8. 每一项怎么复现

### 8.1 Ridge —— 各处必须一致的约定
复用已有实现，不要另写：
- H1 `sua_exploration/scripts/run_h1_ridge_baseline_v2r2.py`
- RT `sua_exploration/mc_maze/rt_classical_comparators.py`
- subject-M A2a-v2 加权对照代码，receipt `b6a080c4...ba58`

固定项：因果 `W` bin × `N` 通道历史窗口、归一化 lambda、**截距不加惩罚**、只用支撑块的归一化统计量、逐 session 拟合。任何超参数都必须**在校准块内部**选择，绝不能使用查询窗口。

### 8.2 Kalman 滤波器 —— 配方
标准速度 Kalman 滤波器，所有参数从校准块闭式求得，无反向传播，因此仍属论文的对照类别。

状态 `x_t` = 位置与速度（subject-M / M2 / RT 为 2 维，H1 为 7 维）加一个常数项。观测 `z_t` = 分 bin 发放率。

```
状态方程：x_t = A x_{t-1} + w_t,   w_t ~ N(0, W)
观测方程：z_t = H x_t + q_t,       q_t ~ N(0, Q)
```

从校准数据用最小二乘拟合：
```
A = X1 X0^T (X0 X0^T)^-1
W = (X1 - A X0)(X1 - A X0)^T / T
H = Z X^T (X X^T)^-1
Q = (Z - H X)(Z - H X)^T / T
```
其中 `X0`/`X1` 为滞后与当前状态矩阵，`Z` 为发放率矩阵。随后在查询块上运行标准预测/更新递归，报告与其他所有臂相同的指标。为数值稳定给 `Q` 加正则下限并记录。逐 session 拟合，不跨 session 迁移。

### 8.3 源域汇聚 ridge —— 按冻结协议执行
先做 Part A：测量单元标识是否跨 session 对应。不存在对应时，报告 `SPR_UNDEFINED_NO_CHANNEL_CORRESPONDENCE` 并不跑任何臂。**绝不要人为制造对应关系。** 然后汇聚 `beta_prior = 源 session 均值`，求解
`beta = (X'X + (lambda+gamma) I)^-1 (X'y + gamma beta_prior)`，其中 `lambda` 与 `gamma` **只在源 session 之间**做留一交叉验证选择。`gamma = 0` 必须精确回退到 scratch ridge，并写入测试断言。

### 8.4 每次复现都要有的完整性闸门
在解释任何新臂之前，先复现该数据集的封存参考值并报告最大偏差。已达到的标准：H1 ridge 为 `0.0`，subject-M ridge 为 `2.24e-6`。闸门失败就**停止** —— 新数字一律作废。这已经拦下过一次运行（见 6.5）。

## 9. 近期工作，2025-2026

**PRI-T**，隐马尔可夫目标推断，Nature BioMed Eng 2025。无监督重校准。其核心发现对我们有利：PRI-T、FA stabilization 与 ADAN 在成对日期上表现**相当**，但**当日期间隔很大时全部失效**，且在链式应用下只有*目标标注类*策略能维持长期控制。我们正是一种稀疏目标标注策略。**作为动机引用，不作为对照** —— 任务与数据都不同。

**MPA**，脉冲网络的测试时适配，arXiv 2606.14866，2026。基于 LoRA 的 TTA，只更新不到 9% 的参数，明确以“NoMAD 对植入式硬件太昂贵”为动机。这是我们在**效率维度**上最接近的竞争者，框架动机相同。需说明的差别：MPA 是无监督的，但在测试时仍做梯度更新；我们完全不做。数值上不可直接比较（数据集不同），应按第 5 节的维度对比。

**ALIGN**，对抗式 session 不变语音解码，PMLR 2026。同一问题，不同模态。作为问题广度引用。

**NoMAD**，Nature Communications 2025。已在我们的参考文献中，现在还可通过 FALCON Table 1 在 H1 和 M2 上直接引用。

## 10. 应当跳过的内容

**重新实现**无监督隐空间对齐（ADAN、NoMAD、CycleGAN、Degenhart 类）或多 session 预训练模型（POYO）。每一个都是完整重实现，各有一整套调参空间；调得不好的重实现比不做对比更糟，因为熟悉该方法的审稿人一眼就能看出。

对 H1 和 M2 而言这一点现在已无意义 —— 第 3 节已在同一端点上提供了 NoMAD 与 CycleGAN 的数字。**引用永远允许，有风险的只是重新实现。**

## 11. 报告规范

1. 超参数只能在校准块内部选择，绝不使用查询窗口。
2. 报告逐 session 配对差值、符号计数和不确定区间，与 carrier 各臂一致。只给均值不够。
3. 不利结果必须与有利结果同表同字号。carrier 在 subject-M M50 上输给稠密 ridge、在 H1 上输给 NDT2 Multi，这两点都必须保持可见。
4. 在每个对照的分数旁标注它消耗的监督量，使精度轴与标签成本轴可分离。
5. 绝不能在对我们有利的数据集上调优对照、而在不利的数据集上保持固定。H1 上调优了 ridge，subject-M 上也必须调优，即使这会扩大我们的劣势。
6. 每个发表的数字都要标注 receipt SHA 与验证器状态。
7. 与引用的 FALCON baseline 对比时只能做**描述性**表述。我们的 held-out 标准差（±0.1272）与多个 baseline 重叠，且主办方不提供逐 session 分数，无法做配对检验。
