## 2. 判读规则（预注册）

> **2026-09-06 执行修订（用户裁定）+ 审核后正式化（REVIEW_MATRIX_H1_L_IDENTITY_V1）**：基线 cell **M-F700（L=700 + proj_add）正式列入矩阵注册表**（matrix_cells.py 增补 + cell_geometry 对 L=700 豁免"仅缩短"约束——700 是原始窗长非缩短），与 M-F250 构成**同注入 L 轴受控对**（同 CAL-2/M3/LODO/配方/seed，唯一变量 L，双卡并行）。原 §2.5"全窗不在矩阵内"表述作废，以本行为准。五臂终局参照锚更新：(a) 0.080 / (b)PROXY 0.178（**PROXY 不得作 M-A 先验，A250 才是首次量真 36-d**）/ (c) add_tail 0.009（**负贡献，< (d)**）/ (d) zero 0.020 / (e) 不再等待（排序已定）。M-C250 先验据此近乎划除。**命名规范：receipt 与口头对齐用「joined / concat / proj_add」等模式名，不用 M-A/M-B 字母（易反）。**

1. **视界判读**（在胜出喂法内）：R²(L) 随 L 降 ≤0.01 → 视界 ≤ 该 L，取最短；降 >0.02/100bin → 记录视界，取拐点前 L；**空洞规则（2026-09-06 预注册）：0.01 < Δ ≤ 0.02 时，以 L=350 作 tiebreaker cell——若 Δ(350) ≤ 0.01 取 350，否则记录视界并取 350**。F250 vs F700 的 Δ 落在 0.01–0.02 时同理按 350 裁决。
2. **喂法判读**（在 L=250）：(b) vs (a) ≥ +0.01 → 低维喂法确立，(a) 降级为对照；(c) 仅在 (a),(b) 双弱时参考。
3. **协同检验**：若 (b) 在短 L 的优势 > (b) 在 350 的优势 → 「硬塞 700 维迫使模型求偿于长历史」假设成立（论文素材）。
4. **对照健全性**：(e) 必须显著劣于同 L 的 (a)/(b)（否则考卷/矩阵有 bug）；(d) 量化 identity 总贡献。
5. 参照系：同配方全窗（L=700, 喂法=胜者）**不在矩阵内**，仅在胜出后作为第二段前的基线 cell 单独跑一次（~4h），使「无损」有同配方基准。

## 3. 依赖与已知风险

- (b) 的 joined36 必须是**真 C2 pre-pool joined**（32+4），不是五臂的 PROXY（前 32 维 fused）——五臂 PROXY 若第一，矩阵用它重定义真表示后仍需重验。
- 五臂 L=100 终局若 (a) 反超（与中期矛盾），矩阵的 (b) 主推降级为 (a) 主推，结构不变只换字母。
- 掩蔽证据显示 H1 信息可能在长尾——L=150/250 有掉分风险，这正是矩阵要量化的；若全长度都显著掉，H1 延迟解转 SPD-C1/C2（流式 KV / 局部带宽），本矩阵结果仍然定视界。
- 留出日期的 session 数要 ≥2（避免单 session 考卷噪声）；具体日期清单执行前写死进 receipt。
