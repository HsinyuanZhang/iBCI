## 3. What changes vs the half-cycle run

Half-cycle: session-head first-M activity + **one payload M3 H-C for every M**.

B2, each optimizer step on session `S`:

1. `M = prefix_schedule(epoch0, 731)[step]`
2. `start =` hash-pick among V1 M4-cache starts for `S` (see §4)
3. **Identity / E0**: interpolated trials `trial_values[start : start+M]` through the frozen C2 materializer
4. **Carrier**:
   - `M ∈ {7,5,4}` → V1 **M4 carrier** for `(S, start)` (4 trials `start:start+4`)
   - `M == 3` → `fit_deployment_carrier` on `trial_values[start : start+3]`, divide by frozen `s_src = 6.8260113140959355e-06` (floor 1e-12)

Deploy / HO-M3 identity+carrier stay **earliest-M3** on each held-out-calib recording (C2 eval law). Not a training-block carrier.
