## Q4 先答（因为 Q1/Q3 依赖它）：墙钟主导是谁 —— 实测推翻"时间核主导"假设

**全窗一次前向的组件占比：**

| 几何 | conv | token MLP | slot MHA | temporal 4L | readout |
|---|---|---|---|---|---|
| M2 (7,50,96) | 2% | 33% | **61%** | 5% | ~0% |
| H1 (1,700,176) | 2% | 41% | **51%** | 5% | ~0% |

两种几何下**空间集合前端合计占 92–94%，时间核只占 5%**。O(W²) 的恐惧在 CPU 上不是当前墙钟——W=700 的时间核全窗仅 33ms（W=350→700 实测比 2.10，受内存/启动开销影响低于 4× 理论）。

**官方 exact-E（前端 k=5 缓存 + 第 4 层 last-query）后的每步成本估算：**
- M2：前端残差（约 5/50 窗口新 token）+ 时间 L1–3 ≈ 前端:时间 ≈ 60:40，每步 ~18ms（本机口径；与实测 cached T2 8.7–8.9ms 同量级，差异来自共享主机与 B）。
- H1：前端残差 4.2ms + 时间 L1–3 25.1ms ≈ **每步 29ms**，前端缓存后时间核反超为主导（15:85）。此前测得的 370–613ms 是**未缓存全路径**，不是 exact-E 的真实成本。

**最大未开发同权等价优化（两任务通用）：静态校准项折叠——范围限定为第一层。**（2026-09-06 修订：原"砍掉 token MLP 绝大部分 FLOPs"说重了。）可折叠的只是第一层 `Linear(local∥E0∥T)` 的静态部分：`W_l·local + cached(W_e·E0 + W_t·T + b)`，消掉第一层静态 GEMM 与 expand/cat 物化；**GELU 与第二层 256→256 仍须对每个新 token 计算**，不在折叠范围内。注意 581973 的官方 M2 wrapper 目前仍在做整段 cat（连 FactoredTokenMLP 都还没有）——所以对官方路径而言，这一刀同时消掉 cat 物化 + 静态 GEMM，是净收益，但预期收益 ≠ 整个 token MLP。slot query/slot_norm(slots) 亦为静态，可一并预计算。

## Q2：加速的等价性分级（哪些同权、哪些新成员）

- **A 级（同权，必须逐点 parity：FP32 下 max|Δ|≤1e-6 且全预测集 digest 纪律）**：静态 E0/T4/HC 项折叠；slot-Q 与 slot_norm 预计算；前端 k=5 缓存（已做）；L4 last-query（已做）；in-place 拷贝消除；固定形状 compile；线程钉扎；inactive 行冻结（需证明 masked 行不影响输出）。验收：对冻结官方路径在全 ext-4/dev 面逐点对账。
- **B 级（同算子族，近似等价，须报误差界 + R² 影响）**：更紧的 causal SDPA kernel；INT8/量化；低精度累加。不得默认采纳，须与 FP32 官方路径对误差并确认 R² 不降。
- **C 级（新成员，须重训 M1/H1 + 质量门，581973 数字不继承）**：跨窗 KV；局部带宽 b；换 QueryAge；任何宽度/层数/slot 数改变；prefix 约定改变。**exact-E 的 last-query 不是新架构**（同意原文档边界）——但跨窗 KV 在窗相对 PE 下确实换了模型，归类正确。

## Q3：H1 W=700 的 exact-E 预算 —— **本机估算 ~25–30ms/步（不作签字）；第一刀是 A 级静态折叠，不是换核**

（2026-09-06 修订：强调本机估算地位与复测义务。）

- ~25–30ms/步与"超设计门 1.7×"均为**本机估算**（7950X/2 线程/合成张量），与官方 CPU 不同机不可换算；本表只能用于**方向与排序**（未缓存→缓存的大幅改善、前端主导）。**A 级做完后的新地板必须在冻结官方路径上复测才能作为任何 go/no-go 依据。**
- 顺序不变：先做 A 级（第一层静态折叠 + slot-Q 预计算），再在冻结路径复测；届时若仍超门，**局部带宽 b 是 C 级新成员**——比换 QueryAge 更同族，但仍要重训 + 质量门，**581973 数字不跟随**。QueryAge 的取舍等 formal12 质量读数，不预判。

## 对原文档的三处修正

1. "时间核前三层每步 O(W²)，W=100/700 会按窗长平方涨"——理论正确但**非当前墙钟主导**（实测 5%）；加速叙事应改为"空间前端（token MLP 静态项 + slot MHA）主导"。
2. "H1 exact-E 是否可接受"不应从 370–613ms 旧数推断——那是未缓存路径；缓存后 ~25–30ms/步。
3. 加速清单 A 项应把"静态 E0/T4 投影只算一次（第一层）+ 消除整段 cat"提为**第一刀**（原文档已列但排序靠后；官方 M2 wrapper 连 FactoredTokenMLP 都还没有，收益真实存在，但范围是第一层静态 GEMM 与物化，不是整个 token MLP）。
4. 本表全部耗时为本机口径（7950X/2 线程/随机权重/合成张量），**只用于占比与排序结论**；任何延迟 go/no-go 必须在冻结官方路径复测后签字。
