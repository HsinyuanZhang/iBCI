# Track-B v2 Subject-M paired live launcher successor

The v2 launcher writes only to the canonical v2 result root and refuses every
v1 path.  Each view owns twenty-two immutable prospective pairs, including a
pre-open target-attempt receipt, a pre-fit target-lineage receipt, exact raw
stdout/stderr pairs even when a stream is empty, one held-FD snapshot-cleanup
receipt, and two reserved forensic stdout/stderr fallback pairs used only if
the canonical four-link stream-group publication fails.  The cleanup receipt
and two forensic fallbacks are the three pairs added to the former nineteen-pair
topology.  Together with the global paired completion this is forty-five pairs.

SUA must complete terminal validation before pMUA starts.  The two views retain
independent source rebuilds and independent 28-session fits.  The v1 failure is
bound as superseded immutable provenance, not as reusable output.
