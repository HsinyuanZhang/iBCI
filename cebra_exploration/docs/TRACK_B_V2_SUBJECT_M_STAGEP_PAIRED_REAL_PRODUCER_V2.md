# Track-B v2 Subject-M paired real producer successor

This execution-only successor preserves the failed v1 tree as immutable
provenance and writes only to the canonical v2 result root.  It repairs the v1
normalizer gate by checking the frozen float32 mean and standard deviation in
the source-adapter authority hash domain: dtype, shape, then contiguous bytes.
No normalizer value, target parser, V9 endpoint, Offset(5,5), model, fit,
readout, decoder, or metric rule changes.

Before a target helper may run, the launcher must publish an immutable target
access-attempt receipt.  After held-FD parsing and before CEBRA fit it must
publish a pre-fit target-lineage receipt.  Parent-captured stdout and stderr
are always retained as separate immutable raw pairs, including when empty.
