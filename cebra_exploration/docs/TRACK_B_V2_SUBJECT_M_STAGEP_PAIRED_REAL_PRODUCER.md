This additive successor closes the reviewable interfaces for the eight paired
Stage-P producers without altering the sealed runtime or opening a target.  It
freezes the development pilot to SUA then independently fitted pMUA for
`sub-M_ses-CO-20140307`, seed 42, one joint 28-session `offset10-model`
CEBRA fit per view at d8/10,000 iterations, and all three readout routes by
ridge and cosine kNN.

The source producer must rebuild the six settled view-specific strict27
continuous-v2 authorities byte-for-byte.  The historical selector-plan member
is lineage only and cannot choose geometry.  Target parsing is permitted only
through the canonical A2-ledger private-snapshot FD using source-only behavior
mean/std.  M50 is the full raw prefix through rewarded-trial-50 stop.  CEBRA
may transform the continuous held suffix beginning at trial 51, but scoring is
restricted to the exact sidecarless V9 post50 valid starts and target bytes.
Each Offset(5,5) receptive field must be wholly inside the held suffix and
support-disjoint.

Checkpoint persistence uses `CEBRA.save(..., backend="sklearn")` to an owned
temporary inode, immutable raw body/sidecar publication, and
`CEBRA.load("/proc/self/fd/N", backend="sklearn", weights_only=True)` from a
verified held FD.  Embeddings use an immutable float32 NPZ bundle with exact
same-byte reload proof.  Reload acceptance compares a recursive solver-state
digest and every persisted role's actual transformed float32 bytes.  The
execution addendum recursively binds the complete vendored CEBRA Python
runtime plus provenance and the complete pinned TorchMetrics 1.5.1 Python
runtime plus distribution metadata.  The current CLI is no-write by default
and its execute path is an unconditional pre-target tripwire pending
independent review and a separately root-minted execution addendum.

This review boundary includes executable helpers and source/synthetic tests,
but it is not an execution authorization.  No Subject-M target was opened, no
GPU was inspected or used, no model was fit on the development target, and no
official addendum or result receipt was minted.
